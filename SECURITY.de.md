# Sicherheitsrichtlinie

[English](SECURITY.md) | [Sicherheitsmodell](docs/de/security.md)

Vorschau ohne Zertifizierung oder garantierte Reaktionszeit. Sicherheitslücken privat über GitHub melden, sofern aktiviert. Andernfalls ohne technische Details einen privaten Kontaktweg anfragen. Keine Geheimnisse, Cookies, Dumps, Roh-XEL oder Data-Protection-Schlüssel in Issues veröffentlichen. Gefährdete Zugangsdaten rotieren. Es wird keine erfundene Kontaktadresse angegeben.
